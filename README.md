# Study Corner

Study Corner is a three-page student learning website made as practice for an HTML and CSS class assignment.

## Pages

- **Home** (`index.html`) — introduction, study reminders, links to other pages, and an image.
- **Resources** (`resources.html`) — study habits, a weekly plan table, and links to HTML and CSS learning resources.
- **Contact** (`contact.html`) — a sample form using text, email, select, radio, checkbox, and textarea fields.

The pages share one stylesheet, `style.css`, and use a small SVG favicon.

## What I practised

- HTML structure, headings, paragraphs, comments, links, and images
- Navigation between pages
- Lists, tables, IDs, and form labels
- CSS selectors, comments, backgrounds, borders, spacing, and the box model
- Widths, max-width, positioning, alignment, typography, and responsive layouts
- Styling tables and form controls

## How to view the website

Open `index.html` in a web browser. Use the navigation links at the top to visit the other two pages.

The contact form is for demonstration only. It does not send messages to a server.
